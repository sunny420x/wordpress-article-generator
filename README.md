## ระบบนี้คืออะไร ?
<strong>WordPress Articles Generator</strong> เป็นปลั๊กอิน WordPress ที่ออกแบบมาเพื่อช่วยให้นักพัฒนาและเจ้าของเว็บไซต์สามารถสร้างบทความคุณภาพสูงพร้อมรูปภาพประกอบอัตโนมัติได้อย่างรวดเร็วผ่าน <strong>Google Gemini API</strong>

## วิธีการติดตั้ง

## การตั้งค่า API
1. ไปที่เมนู **Articles Generator > ตั้งค่าระบบ**
2. ใส่ Google Gemini API Key และเลือกโมเดลสำหรับสร้างบทความ
3. ระบบจะใช้ Google Gemini API Key เดิมสร้างภาพปกด้วยโมเดล Imagen และตั้งเป็น Featured Image อัตโนมัติ

การสร้างภาพใช้ Gemini Imagen API โดยบัญชีหรือโมเดลบางประเภทอาจต้องเปิดใช้งาน billing และมีโควตาแยกต่างหาก ระบบจะยังสร้างบทความเป็น Draft ได้แม้การสร้างภาพล้มเหลว
สามารถติดตั้งปลั้กอินนี้ได้โดยการดาวน์โหลดไฟล์นี้จาก Github หน้านี้ และอัพโหลดลงในหน้า /wp-admin/plugin-install.php หลังจากอัพโหลด 
และเปิดใช้งาน (Activate) ระบบจะทำการสร้างตารางและคอลัมน์ใหม่จากตารางเดิมโดยอัตโนมัติ
